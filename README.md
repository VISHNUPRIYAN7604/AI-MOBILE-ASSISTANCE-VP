# SmartMobile AI Assistant

AI-Powered Mobile Settings Guidance and Control Assistant

## How to run

1. ZIP file extract pannu
2. `index.html` file browser la open pannu
3. No server needed — direct open panna mudiyum!

## Project structure

```
smartmobile-ai/
├── index.html       ← Main page
├── css/
│   └── style.css    ← All styles
├── js/
│   └── app.js       ← Chatbot logic
└── README.md
```

## Features

- AI Chatbot (Tamil/Tanglish support)
- Quick action buttons (Torch, WiFi, Bluetooth, etc.)
- Settings guide cards
- Device status toggles
- Smart suggestions
- Voice mic button
- Stats dashboard

## Tech stack

- HTML5, CSS3, Vanilla JavaScript
- No external libraries needed
